# 🚀 PDFMerge
A backend Restful API built with .NET 9 and C# to help users manage their files.

## ✨ Key Features
PdfMerge Web API is a system that allows users to:

* Merge multiple files into a single one.
* Uploading files.
* Converting images to pdf files.
* Downloading files.
* Validating allowed types such as: png, jpg, gif, pdf.
* Deleting files.

## 🛠 Tech Stack

* **Language:** C#
* **Framework:** .NET 9 / ASP.NET Core WEB API
* **ORM:** Entity Framework Core
* **Files library:** PdfSharp.
* **API Documentation:** Swagger

## 🚀 Getting Started
To run this project locally, follow these steps:

1. **Clone the repo:**
git clone https://github.com/yllka-shala/PDFMerge.git

2. **Open the solution:**
Open `PdfMergeApi.sln` in Visual Studio.

3. **Run:**
Press `F5` to build and launch the app.
